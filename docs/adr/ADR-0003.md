# ADR - 0003

**Título:** Decisão sobre imagem utilizada no docker  
**Data:** 07/11/2026    
**Responsável:** Filipe Arantes   
**Status:** Aceito  

**Contexto:** Ao começar a configuração do docker precisa ser decidido que tipo de imagem ser utilizada para o container

**Decisão:** Foi decidido utilizar o as imagens php:fpm no compose e php:8.4-fpm no Dockerfile

**Justificativa:** Eu primeiramente utilizei o alpine por causa de um video que assisti, mas percebi que utilizando o alpine perdia muitas funcionalidades não dava nem para acessar o container como bash. Os comando de adicionar as extensões necessarias também eram diferentes do que eu conheço, então decidi voltar as imagens normais utilizadas em outros projetos que participo
