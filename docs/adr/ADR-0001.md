# ADR - 0001

**Título:** Decisão sobre linguagem utilizada  
**Data:** 06/11/2026    
**Responsável:** Filipe Arantes   
**Status:** Aceito  

**Contexto:** Ao iniciar o desenvolvimento do sistema de venda de ingressos, ainda sem frameworks ou ORMs é preciso decidir a linguagem utilizada para o sistema.  

**Decisão:** Utilizar PHP pela grande gama de sites e documentações ja consolidadas no mundo, fazendo ser de facil acesso essas informações.

**Justificativa:** Além da familiaridade da equipe com a linguagem, e ainda mais como essa primeira etapa é monolitica o PHP é a linguagem com o maior nivel de sistemas monoliticos.
