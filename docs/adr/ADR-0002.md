# ADR - 0002

**Título:** Decisão sobre tecnologia de banco de dados  
**Data:** 06/11/2026    
**Responsável:** Filipe Arantes   
**Status:** Aceito  

**Contexto:** Ao iniciar o desenvolvimento do sistema de venda de ingressos, ainda sem frameworks ou ORMs é preciso decidir a tecnologia utilizada do banco de dados.  

**Decisão:** Decidido utilizar PostgreSQL que é um banco de dados relacional facilitando integrações entre muitos dados, com as relações entre tabelas.

**Justificativa:** Um motivo parecido com a linguagem, mas além de familiaridade é um SGBD que pode realmente rodar em produção sem custos diferente de outros como SQLServer e não foi escolhido SQLite ou esses bancos em JSON pois são mais complicados de escalar pra grandes quantidade de usuarios.
